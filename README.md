# 🚗 Sistema de Gestión de Concesionario / Venta de Vehículos

> Proyecto académico desarrollado en **equipo** para la asignatura de **Programación**.

Aplicación de escritorio desarrollada en **Java** con interfaz gráfica **JavaFX**, persistencia en **MySQL** implementando el patrón de diseño **DAO (Data Access Object)** y gestionada con herramientas de compilación y dependencias mediante **Maven**.

---

## 👥 Sobre el Proyecto

Este repositorio contiene el trabajo final desarrollado en equipo para la asignatura de **Programación**. El objetivo principal del proyecto es aplicar de forma práctica los conceptos clave de la materia, tales como:
- Programación Orientada a Objetos (POO) y modularidad.
- Conexión e integración de aplicaciones Java con bases de datos relacionales (**MySQL**) mediante JDBC.
- Implementación de patrones de arquitectura y acceso a datos (**DAO**).
- Diseño y maquetación de interfaces gráficas interactivas con **JavaFX** y hojas de estilo **CSS**.
- Gestión de dependencias y automatización de la construcción con **Maven**.
- Control de versiones y trabajo colaborativo con **Git/GitHub**.

---
## 📂 Estructura del Proyecto

El repositorio sigue la convención estándar de proyectos Maven:

```text
├── pom.xml
├── .gitignore
└── src/
    └── main/
        ├── java/
        │   └── org/
        │       └── example/
        │           ├── exceptions/             # Clases para manejo y captura de excepciones
        │           ├── utils/                  # Clases de utilidad y ayuda general
        │           ├── Cliente.java            # Modelo: Entidad Cliente
        │           ├── ClienteDAO.java         # Interfaz DAO para Cliente
        │           ├── ClienteDAOMySQL.java    # Implementación MySQL para Cliente
        │           ├── Vehiculo.java           # Modelo: Entidad Vehículo
        │           ├── VehiculoDAO.java        # Interfaz DAO para Vehículo
        │           ├── VehiculoDAOMySQL.java   # Implementación MySQL para Vehículo
        │           ├── Venta.java              # Modelo: Entidad Venta
        │           ├── VentaDAO.java           # Interfaz DAO para Venta
        │           ├── VentaDAOMySQL.java      # Implementación MySQL para Venta
        │           ├── ConexionDB.java         # Singleton/Gestión de la conexión JDBC
        │           ├── PropertiesReader.java   # Lector de configuraciones (database.properties)
        │           └── MainApp.java            # Punto de entrada de la aplicación JavaFX
        └── resources/            
            ├── styles.css                      # Hojas de estilo para la interfaz gráfica
                                   
```

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Java (JDK 21+)
- **Interfaz Gráfica:** JavaFX
- **Gestor de Dependencias:** Maven
- **Base de Datos:** MySQL
- **Conector JDBC:** `mysql-connector-j`
